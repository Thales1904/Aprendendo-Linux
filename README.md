# Linux — Estudos de Linha de Comando

## Sobre o projeto

Este repositório reúne meus estudos práticos de Linux e linha de comando, desenvolvidos a partir da leitura do livro *The Linux Command Line*, de William Shotts.

O objetivo é registrar os conhecimentos adquiridos durante a leitura, praticar os comandos apresentados no livro e documentar os resultados por meio de exemplos, arquivos de teste e capturas de tela dos comandos executados no terminal.

O projeto está organizado por partes do estudo, permitindo acompanhar o conteúdo aprendido, consultar exemplos práticos e revisar os comandos posteriormente.

## Estrutura do repositório

```text
Linux/
├── README.md
└── Parte1/
    ├── README.md
    ├── prints/
    └── playground/
        ├── arquivos .csv
        ├── arquivos .txt
        └── outros arquivos de teste
```

### Descrição das pastas e arquivos

- **`README.md`**: apresenta o projeto, seus objetivos e sua estrutura geral.
- **`Parte1/`**: reúne os estudos referentes à primeira parte do livro.
  - **`README.md`**: documenta os conceitos e comandos estudados, com explicações e links diretos para as capturas de tela que demonstram sua execução.
  - **`prints/`**: armazena capturas de tela dos comandos executados no terminal, servindo como registro visual das práticas realizadas.
  - **`playground/`**: contém arquivos utilizados nos exercícios e experimentos, como arquivos `.csv` e `.txt`, para testar comandos e observar seu comportamento em situações práticas.

## Objetivos de aprendizagem

- Desenvolver familiaridade com a linha de comando e o ambiente Linux.
- Compreender a sintaxe e o funcionamento dos comandos estudados.
- Praticar operações com arquivos, diretórios e conteúdo textual.
- Utilizar arquivos de teste para experimentar comandos em diferentes situações.
- Documentar os aprendizados de forma organizada, com exemplos e evidências práticas.
- Construir uma referência pessoal para futuras consultas e revisões.

## Progresso dos estudos

O repositório será atualizado conforme o avanço na leitura e na prática dos conteúdos. Inicialmente, contempla a primeira parte do livro e os estudos realizados até aproximadamente a metade da segunda parte.

Novas seções poderão ser adicionadas para acompanhar a evolução dos estudos e ampliar a documentação dos comandos e conceitos aprendidos.

## Referência
